# Data Dictionary

All internal data is synthetic, for the fictional company GulfChem Industries, covering January 2023 to December 2025. Generated by `src/generate_data.py`. Price trends follow real FRED indices in `data/external/price_indices.csv`.

## How the tables connect

```
sites ──┐
        ├── po_lines ── goods_receipts      (po_number + po_line)
vendor_master ──┤  └──── invoices            (po_number + po_line)
        │       └── contract_id ── contracts ── contract_rates
categories ─────┘
item_master ── material_number ── po_lines, contract_rates, wo_parts
equipment ── work_orders ── wo_parts
```

## sites.csv — the five plants

| Column | Description |
|---|---|
| site_id | Plant code: BTR, LCH, FRP, PAS, CNR |
| site_name | Plant name |
| state | LA or TX |
| size_factor | Relative plant size; scales purchasing volume |
| turnaround_start | Start date of the plant's turnaround in the period |
| turnaround_days | Turnaround duration in days |

## categories.csv — maintenance category taxonomy

| Column | Description |
|---|---|
| category_code | C01 to C12 |
| category_name | For example, Valves & Actuators, Scaffolding Services |
| kind | material or service |

## item_master.csv — material master for stocked items

| Column | Description |
|---|---|
| material_number | Unique material ID, as in SAP |
| description | Standard description |
| unit | Unit of measure |
| category_code | Category of the material |

## vendor_master.csv — supplier records (SIM-style data)

Messy by design: one real supplier can have several vendor records with different spellings.

| Column | Description |
|---|---|
| vendor_id | Unique vendor record ID |
| vendor_name | Name as entered; spellings vary across duplicate records |
| city, state | Supplier location |
| tax_id | Federal tax ID; shared by duplicate records of the same supplier, missing for some |
| status | Active, Inactive, or Blocked |
| status_reason | Why a vendor is blocked |
| blocked_date | Date the vendor was blocked |
| default_payment_terms_days | Payment terms when there is no contract |
| safety_emr | Contractor safety rating (Experience Modification Rate); below 1.0 is better than average |
| insurance_expiry | Date the contractor's insurance certificate expires (contractors only) |
| created_date | Date the vendor record was created |

## contracts.csv — negotiated agreements

| Column | Description |
|---|---|
| contract_id | Unique contract ID |
| vendor_id | Vendor record the contract was set up under |
| supplier_name | Supplier legal name |
| category_code | Category covered |
| start_date, end_date | Contract validity period |
| payment_terms_days | Agreed payment terms (45 or 60 days) |
| markup_cap_pct | Maximum mark-up allowed on pass-through materials, where applicable |
| sites_covered | Plants the contract covers |

## contract_rates.csv — rate cards

| Column | Description |
|---|---|
| contract_id | Contract the rate belongs to |
| rate_year | Year the rate applies (rates escalate each January, capped at 4%) |
| item_code | Internal item ID |
| material_number | Material number, for stocked items |
| description | Item or service description |
| unit | Unit of measure |
| contract_rate | Agreed price per unit |

## po_lines.csv — purchase order lines

| Column | Description |
|---|---|
| po_number, po_line | Purchase order and line number; together they form the key |
| site | Plant, typed inconsistently in some lines |
| vendor_id, vendor_name | Vendor record used for the purchase |
| requisition_date | Date the request was raised (missing for a few lines) |
| po_date | Date the purchase order was issued |
| category_code | Category; missing for about 15% of lines |
| material_number | Material number; services and some materials have none |
| description | Free-text description, often abbreviated or misspelled |
| quantity | Quantity ordered |
| unit | Unit of measure, typed inconsistently |
| unit_price | Price per unit on the PO |
| line_amount | quantity × unit_price |
| contract_id | Contract referenced, if any |
| currency | Always USD |

## goods_receipts.csv — deliveries and completed work

| Column | Description |
|---|---|
| gr_id | Goods receipt ID |
| po_number, po_line | PO line received against |
| promised_date | Date the supplier committed to |
| actual_date | Date delivered or work completed |
| qty_received | Quantity received (can be less than ordered) |
| qty_rejected | Quantity rejected for quality problems |

## invoices.csv — supplier bills

| Column | Description |
|---|---|
| invoice_id | Internal invoice record ID |
| invoice_number | Supplier's invoice number |
| vendor_id | Vendor that billed |
| po_number, po_line | PO line billed against |
| invoice_date | Date of the invoice |
| invoice_qty | Quantity billed |
| invoice_unit_price | Price per unit billed |
| invoice_amount | invoice_qty × invoice_unit_price |
| passthrough_cost | Contractor's underlying cost, for pass-through materials only |
| markup_pct_billed | Mark-up the contractor applied, for pass-through materials only |
| payment_terms_days | Terms that applied to the purchase |
| paid_date | Date GulfChem paid the invoice |

## equipment.csv — plant equipment register

| Column | Description |
|---|---|
| equipment_id | Unique equipment tag |
| site_id | Plant |
| equipment_type | Centrifugal Pump, Compressor, Control Valve, Heat Exchanger, or Electric Motor |
| criticality | A (most critical) to C |
| install_year | Year installed |

## work_orders.csv — maintenance jobs

| Column | Description |
|---|---|
| wo_id | Work order ID |
| site_id | Plant |
| equipment_id | Equipment worked on |
| wo_type | PM (preventive) or CM (corrective, after a failure) |
| created_date, completed_date | When the job was raised and finished |

## wo_parts.csv — spare parts used

| Column | Description |
|---|---|
| wo_id | Work order that used the parts |
| material_number | Part used |
| qty_used | Quantity consumed |

## data/external/price_indices.csv — real FRED data

| Column | Description |
|---|---|
| date | Month |
| index_name | STEEL, VALVES, PUMPS, or LABOR |
| series_id | FRED series ID (WPU1017, WPU114902, WPU1141, CES2000000003) |
| description | Series name |
| value | Index value |
